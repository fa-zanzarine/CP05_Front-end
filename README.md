# Melodia - Front-End

## 📖 Descrição do Projeto

O **Melodia** é a landing page de um aplicativo de música fictício, desenvolvida com o objetivo de apresentar o app, seus diferenciais e captar interesse de novos usuários.

O projeto consiste no desenvolvimento de uma página web responsiva de uma única página (one page), utilizando HTML, Tailwind CSS e JavaScript puro. A página apresenta o app através de uma seção de destaque (hero), os principais benefícios, funcionalidades, depoimentos de usuários e um formulário de contato, com componentes visuais que facilitam a navegação e proporcionam uma experiência de usuário mais agradável.

## 🎯 Objetivo do Projeto

Desenvolver uma landing page responsiva para um aplicativo de música, utilizando tecnologias e ferramentas voltadas para desenvolvimento Front-End.

O projeto busca aplicar conceitos de:

- Estruturação de páginas web;
- Utility-first CSS com Tailwind;
- Design responsivo;
- Uso de biblioteca de ícones;
- Personalização de fontes;
- Criação de formulários;
- Interatividade com JavaScript;
- Desenvolvimento de uma interface visualmente coesa.

## 🚀 Tecnologias e Ferramentas Utilizadas

- **HTML:** Estruturação da página e conteúdos do site.
- **Tailwind CSS:** Framework CSS utilizado via CDN para estilização e responsividade — todo o projeto usa só classes utilitárias, sem arquivo de CSS próprio.
- **JavaScript:** Interatividade do menu mobile e do efeito de transparência do cabeçalho.
- **Font Awesome:** Biblioteca de ícones para elementos da interface.
- **Google Fonts:** Biblioteca de fontes gratuitas (Poppins) utilizada para estilização dos textos.

## 🧩 Seções da Página

### 1. 🧭 Cabeçalho (Header)

Menu fixo no topo da página, contendo logo, links de navegação (Benefícios, Funcionalidades, Depoimentos, Contato), botão de destaque e menu mobile (hambúrguer). O cabeçalho começa transparente e fica sólido conforme a página é rolada, via JavaScript.

### 2. 🎵 Hero (Início)

Primeira seção da página, com o título de impacto, uma breve descrição do aplicativo, botões de chamada para ação (CTA) e uma imagem de destaque representando o app.

### 3. ⭐ Benefícios

Seção com os 4 principais diferenciais do aplicativo (qualidade de som, playlists personalizadas, descoberta de artistas, interface intuitiva), cada um com um ícone do Font Awesome.

### 4. 🛠️ Funcionalidades

Apresentação de 3 funcionalidades do app (Mix diário, Playlists únicas, Radar de artistas) em cards visuais.

### 5. 💬 Depoimentos

Citações de usuários satisfeitos, com foto de perfil e nome, reforçando a credibilidade do aplicativo.

### 6. 📩 Formulário de Contato

Formulário para captar interesse de novos usuários, com campos para:

- Nome;
- Telefone;
- E-mail.

O objetivo é permitir que interessados deixem seus dados de contato de forma simples e organizada.

### 7. 🦶 Rodapé (Footer)

O rodapé apresenta informações importantes sobre o app, incluindo:

- Informações de contato;
- Links para redes sociais;
- Direitos autorais.

## 🔧 Tarefas de Desenvolvimento

### 📐 Estruturação com Tailwind

Organização das seções e componentes utilizando classes utilitárias do Tailwind (`flex`, `grid`, espaçamentos, cores), sem nenhum CSS escrito à mão.

### 📱 Responsividade

Garantir que o layout seja responsivo para diferentes tamanhos de tela, realizando ajustes em:

- Grids e colunas (`sm:`, `md:`, `lg:`);
- Margens e espaçamentos;
- Tamanhos de fonte;
- Menu (versão desktop e versão mobile).

### 🧩 Interatividade com JavaScript

Implementação de duas interações com JavaScript puro:

- Abrir/fechar o menu no celular;
- Deixar o cabeçalho sólido conforme a página é rolada.

### 🎨 Estilização Personalizada

Definição de uma paleta de cores (roxo, magenta e laranja em degradê, sobre um fundo escuro) e de uma fonte personalizada (Poppins), configuradas diretamente no Tailwind, criando uma identidade visual própria para o Melodia.

## 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes dispositivos e tamanhos de tela. A utilização do Tailwind permite que os elementos da interface se adaptem conforme o espaço disponível, proporcionando uma experiência adequada em:

- 💻 Desktops;
- 💻 Notebooks;
- 📱 Smartphones;
- 📱 Tablets.
